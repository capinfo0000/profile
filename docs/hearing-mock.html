段階公開プラン

「必要な箇所ができたら公開し、ポートフォリオは随時追加」というご方針にあわせて、3段階に分けました。公開までの作業量が大きく下がります。

段階やること撮影この時点の状態
第1段階

飲みゲーム／crafy（キャンペーンサイト）／revenge.co.jp		 3枚
実物が見られるので各1枚でよい		 この時点で公開できる。空っぽに見えない
第2段階

任意		 Blog・更新情報、検索対策の追い込み — 必要になったら

要点は「誰でも見られる3本を先に出す」ところです。この3本は実物へのリンクを出すだけで伝わるので、取説を書く必要がありません。 撮影3枚で公開までたどり着けます。ログインが必要な5本は、写真を撮りためながら後から足していく形になります。

この進め方だと、一覧は必ずデータファイル管理にする必要があります 「随時追加」ということは、公開後も繰り返し一覧に手を入れるということです。
トップページのHTMLを毎回書き換える作りにすると、追加のたびにレイアウトを壊すリスクを抱えることになり、そのうち追加自体が億劫になります。 一覧データを1ファイルにまとめ、1件追加するときは、そこに数行足すだけで済む作りにします。ここは選択ではなく、ご方針から自動的に決まる要件です。

06b

デザイン方針（メイン参考：unshift.jp）

いただいたキャプチャとページのソースから、参考サイトの作りを確認しました。unshift.jp は制作会社ではなく、東京の個人開発者のポートフォリオです（トップの一文「私は東京を拠点とするクリエイティブ／フロントエンド開発者です」）。今回と同じカテゴリのサイトなので、参考先として的確です。

要素unshift.jp の作り
作品の見せ方全画面で1件ずつ表示（58 / 60）。矢印キー・スクロール・スワイプで送る
画面の使い方中央に作品画像1枚。操作UIはすべて四隅に固定（左上ロゴ／右上ナビ・設定／下中央ページ送り／右下メニュー）
背景作品ごとに色と形を変える幾何学パターンが、常に動いている。ハミダシ＝ピンク＋青紫のダイヤ／野菜＝ベージュ＋ピンクの同心円／Property Agent＝グレーの三角。作品の配色から背景を生成している
連動貼り紙ラベルとカーソルの色も作品に連動（Property Agent では両方とも赤）
ナビ「トップ／作品／について」の3つだけ。大きめの文字に広い字間
画像の縁直角の長方形ではなく、縁が破れている。紙を手でちぎったような輪郭
タイトル左下に貼り紙風の黒いラベル。文字が少しズレて二重に刷られたような効果つき
カーソル四角形と「詳細はこちら」がマウスに追従。作品の明暗に応じて黒⇄白に反転する
設定パネル来訪者が選べる：表示モード（満杯／単純／最小）、メニュー位置（右下／左下／右上）、ライト／ダークモード
切り替え演出画像が砕けて次に変わる。Nuxt.js＋canvas（WebGL）による生成描画
技術詳細ページのタグ欄に本人が明記：GLSL / three.js / WebGL / クリエイティブコーディング。動きの正体はシェーダー

★ 動画から判明した最重要点

  • 配色の生成ページ全体の色が、作品1つの色から作られている。水曜日のカンパネラ（紫）では背景パターン・タイトルラベル・タグの丸ボタン・「閉鎖されています」枠まですべて紫。Property Agent（赤）ではラベルもカーソルも赤
  • 実現性静的HTMLで完全に同じことができる。一覧データに色を1つ持たせ、CSS変数に流すだけ。JavaScriptもシェーダーも不要
  • 評価unshift.jp が凝って見える理由のかなりの部分がこの仕組み。今回いちばん費用対効果が高い採用候補
「動いている」部分の正体はシェーダーです 背景の幾何学パターンが常時アニメーションし、しかも作品ごとに色と形が変わります。これは GLSL（シェーダー言語）で1フレームずつ描画しているもので、静的HTMLで同じものは作れません。unshift.jp 本人がタグに GLSL / three.js / WebGL と書いています。
ただし、寄せる方法はあります（次表）。「同じもの」は無理でも「同じ方向」には行けます。
やりたいこと静的HTMLでの手段差
背景に幾何学パターン SVGのパターンを敷く。ファイル1つで済む 差はほぼない
パターンがゆっくり動く CSSアニメーションで平行移動・回転させる 単調な繰り返しになる。シェーダーのような有機的な揺らぎは出ない
プロダクトごとに色が変わる 一覧データに色を1つ持たせ、CSS変数に流す 差はない。むしろ管理しやすい
ラベル・カーソルも色が連動 同じCSS変数を参照させるだけ 差はない
画像が砕けて切り替わる — 再現不可。WebGLが要る

切り替え演出をコマ送りで分解すると、こうでした。グリッチ系のシェーダーです。

順起きていること
1画像が上下2枚に割れて飛び去る
2それぞれが横方向の短冊に千切れる
3RGBがズレる（マゼンタ・シアン・緑の縁が出る）
4次の作品名が中央にフェードイン。同時に背景パターンの色も次の作品の色へ変わる

つまり「作品ごとに背景と装飾の色が変わる」ところまでは差がなく、動きの質感だけが落ちます。ここが今回の落としどころだと考えます。

そのままの構成は今回に合いません unshift.jp の作品は「水曜日のカンパネラ 公式サイト」のような、画像1枚で成立する制作物です。全画面1件ずつのビューアは、作品が視覚的に強いからこそ機能します。
今回のサービス開発6本はログインが必要な業務アプリで、画面の中身は入力欄と一覧表です。全画面に引き伸ばしても絵として持たず、クリックしてもログイン画面に着きます。構成は借りず、見た目の作法だけを借りるのが正解です。

では何を採るか。❓ が付いているものは、ご判断をいただきたい項目です。

参考サイトの要素今回理由
配色（ほぼ白＋作品だけが色を持つ）採る画面写真が主役の今回と相性が良い。静的HTMLで問題なく実現できる
四隅にUIを固定するレイアウト採る中央を写真に明け渡せる。CSSだけで実現できる
ナビは3つだけ・広い字間採る今回も Works / About / Contact の3つ。そのまま合う
ライト／ダークモード切り替え採る確定済みのスマホ対応と同じ仕組みで入る。追加負担が小さい
うっすらした幾何パターンの背景採る白一色より締まる。画像1枚で済む
画像の破れた縁要確認静的HTMLで実現できます。マスク画像を1枚用意すれば、全部の写真に同じ縁が付く。JavaScriptは不要
貼り紙風のタイトルラベル要確認CSSだけで実現できます。二重にズレた効果も含めて。画像も不要
カーソルの明暗反転要確認実現可。一覧データに「この写真は明るい／暗い」を1項目持たせるだけで足りる
スクロールで要素がふわっと出る要確認静的HTMLのまま実現可。ただし入れるほどスマホでの表示が重くなる
カーソル追従の「詳細はこちら」要確認実現可。ただしスマホでは表示されないため、PC限定の装飾になる
数字がめくれるページ送り表示要確認今回は一覧形式のため、そもそも出番がないかもしれない
来訪者が選べる設定パネル要確認表示モード3種を作り分ける必要があり、実質サイトを3つ作るのに近い。ライト／ダークだけに絞ることを推奨
全画面1件ずつのビューア採らないログイン必須の業務画面には不向き（上記）
画像が砕ける切り替え演出採らないcanvas（WebGL）による生成描画。静的HTMLの方針と、写真を軽くする方針の両方に反する

要点は「構成ではなく、静けさを借りる」ことです。unshift.jp が良く見えるのは、余白が広く、色を作品にしか使わず、操作UIを画面の端に追いやっているからです。この3つは今回そのまま効きます。むしろ業務画面のスクリーンショットは地味なので、周りが静かなほど写真が引き立ちます。

そしてWebGLが必要なのは「切り替わる瞬間」だけでした。止まっている状態の破れた縁と貼り紙ラベルは、マスク画像1枚とCSSで作れます。署名になっている見た目は、静的HTMLのまま採用できます。

ただし、方向性として合うかは別問題です 破れた縁と貼り紙ラベルは、手作りっぽさ・勢いのある見た目です。unshift.jp は色鮮やかな広告・音楽系の制作物が並ぶので、この荒さが似合います。
今回のサイトは、採用担当や取引先に「業務システムを任せられる人」として見られる場でもあります。破れた縁は目を引きますが、堅さや信頼感とは逆方向に働きます。好みの問題ではなく、誰に何と思われたいかの問題なので、ここは決めていただきたい項目です。

  • 破れた縁・貼り紙ラベルを採用しますか

    A. 採用する（印象重視）B. 直角のまま静かに（信頼感重視）C. 受託制作の2本だけ採用

  • 背景の幾何学パターンをどこまでやりますか

    参考サイトはシェーダーで常時アニメーションしています。静的HTMLでは同じにできませんが、段階的に寄せられます。

unshift.jp とはまったく別物でした。真っ黒な画面に、3Dスキャンした本人の頭部が置かれ、粒子の雲 → ワイヤーフレーム → 実体、と変形し続けます。音つき。1画面で完結し、スクロールはありません。肩書きは Technical Director / Interaction Designer。

要素daijima.jp の作り今回

こちらも three.js の作品そのもので、構成は借りられません。採れるのは「極端な引き算」の作法だけです。ロゴを作らず氏名をそのまま組む、ナビは3語、要素をこれ以上ないほど減らす。
なお daijima.jp は作品を1つも並べていません。サイト自体が作品だからです。今回は7本＋2本を見せることが目的なので、この構成は取れません。
