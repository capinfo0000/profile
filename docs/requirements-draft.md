# 要件定義メモ（ドラフト）

ポートフォリオサイト（取扱説明つき） / engineer.v2008.coreserver.jp

- 状態: ヒアリング中（第2版）
- 最終更新: 2026-08-07
- ヒアリング用仮モック: `docs/hearing-mock.html`

---

## 1. 背景・目的

作ったプロダクトを複数、コアサーバーのサブドメインで運用している。
それらを紹介する自分のホームページを、メインドメインに作りたい。

各プロダクトは **利用にログインが必要**。来訪者にIDとパスワードを渡すことはできないため、
サイト上では **スクリーンショットと説明文による「取扱説明」** の形で見せる。

サイトの主役はポートフォリオ（作ったもの）。自己紹介も載せるが従。

## 2. 確定事項

| 項目 | 内容 |
|---|---|
| 公開URL | engineer.v2008.coreserver.jp のまま（独自ドメインは取得しない） |
| サーバー | コアサーバー v2008（Apache / PHP 利用可） |
| 実装方式 | 静的HTML／CSS（WordPressは使わない） |
| サイトの主役 | ポートフォリオ。作ったものを見せることが目的 |
| 各サービスの前提 | ログインが必要。来訪者は実物を操作できない |
| 見せ方 | 画面写真＋説明文で「取説」として見せる |
| リンク | 各サブドメインへのリンクは出す。ID・パスワードは掲載しない |
| 自己紹介 | 載せる（About あり） |
| 画面写真 | ダミーデータを入れた状態で撮り直す。実データは使わない |
| お試しアカウント | 用意しない |
| お問い合わせ | 入力フォームを設置する |
| スマホ対応 | する |
| アクセス解析 | 入れる（Google アナリティクス） |
| 画像拡大 | クリックで大きく表示できるようにする |
| 常時SSL | 無料SSLを有効化し、http は https へ自動転送 |
| プライバシーポリシー | 掲示する（フォームでの個人情報受領 ＋ クッキー利用のため） |

## 3. ページ構成

| ページ | 内容 | 判断 |
|---|---|---|
| トップ | 一言紹介／作ったもの一覧（写真つきカード）／連絡先への導線 | 必須 |
| プロダクト詳細 | 1プロダクトにつき1ページ。概要／画面写真での操作説明／使用技術／サービスへのリンク | 必須（要否は要確認） |
| About | プロフィール、経歴、使える技術、資格 | 必須 |
| Contact | 入力フォーム（名前・メール・本文）＋送信完了表示 | 必須 |
| プライバシーポリシー | 個人情報の扱い、クッキー利用の告知 | 必須 |
| Blog / 更新情報 | 開発記録・リリースノート | 要否を確認 |

## 4. 非機能要件

| 分類 | 内容 | 状態 |
|---|---|---|
| サーバー | コアサーバー v2008 / Apache・PHP 利用可 | 確定 |
| 常時SSL | 無料SSL有効化、http → https 自動転送 | 確定 |
| 表示端末 | PC・スマートフォン・タブレット | 確定 |
| 画像の扱い | ダミーデータで撮影。公開前に写り込みチェックを1回実施 | 確定 |
| 個人情報 | フォーム経由で氏名・メールを受領。プライバシーポリシーを掲示 | 確定 |
| 迷惑メール対策 | フォームに自動送信よけを設置 | 方式を確認 |
| 表示速度 | 画像を軽量化して読み込みを速くする | 確定 |
| 検索対策 | ページごとの title / description、OGP、sitemap.xml | 要否を確認 |
| バックアップ | サイトのファイル一式を手元にも保管 | 方法を確認 |

## 5. 公開前チェック（写り込み対策）

画面写真はダミーデータで撮り直す方針だが、以下は写り込みが起きやすいため公開前に必ず確認する。

1. ブラウザのURLバー・タブに社内向けアドレスや別サービス名が写っていないか
2. ログイン画面の入力欄にIDが残っていないか
3. 通知バッジ・履歴・入力サジェストに実在の氏名が出ていないか
