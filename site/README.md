# site/

ポートフォリオサイト本体（静的HTML／CSS／素のJS。ビルド不要）。

そのままコアサーバーの公開ディレクトリへ置けば動く。外部ライブラリ・CDNなし。

## ファイル

| パス | 役割 |
|---|---|
| `index.html` | トップ |
| `works.html` | 作品ビューア（1件ずつ全画面で送る） |
| `about.html` | について |
| `data/works.js` | **作品一覧。増減はここだけ直す** |
| `assets/css/style.css` | 全ページ共通。色・書体・余白は先頭の `:root` に集約 |
| `assets/js/pattern.js` | 背景の幾何学模様（四分木＋ハッシュ） |
| `assets/js/viewer.js` | 作品の描画（たわみ）と切り替え（渦＋RGBずれ） |
| `assets/js/artwork.js` | 作品画像の仮生成。**本番はスクリーンショットに差し替える** |
| `assets/js/app.js` | 画面のつなぎ込み（送り・カーソル・詳細・設定） |

## 作品を1件足すとき

`data/works.js` の配列に1つ足すだけ。HTMLには触らない。

```js
{
  id: 'newone',                 // 一意。画像のキーにも使う
  title: 'New Product',         // ラベルに出る英字
  sub: '新しいプロダクト',        // ラベル下の日本語
  category: 'サービス開発',       // サービス開発 / Web制作
  role: '企画・開発',
  tech: ['PHP', 'MySQL'],
  color: '#3E6BE0',             // この作品の色。背景・ラベル・カーソルに流れる
  access: 'login',              // open | login | closed
  url: 'https://...'
}
```

`color` を決めるだけで、背景パターンの色み・タイトルラベル・カーソル・技術タグが
まとめてその色に寄る。参考サイト unshift.jp のいちばんの仕掛けがこれ。

## 作品画像を本物にするとき

いまは `assets/js/artwork.js` が色から抽象画をその場で描いている。
実際のスクリーンショットに替えるときは、`viewer.js` の `_getArt()` が返す
`{ canvas, r, g, b }` を画像から作るように差し替える。

- `canvas` … 表示用
- `r` / `g` / `b` … 切り替え演出のRGB分解（`artwork.js` の `channel()` がそのまま使える）

画像は撮影時にダミーデータを入れること（要件定義 5章）。

## 動作の要点

- **背景パターン** … 画面を四分木で割り、葉のマスにモチーフを1つ描く。
  模様はグリッド座標のハッシュで決まるので、ゆっくり流しても模様が入れ替わらない。
- **たわみ** … 画像を縦の短冊に切り、`drawImage` の描画先を上下にずらす。
- **切り替え** … `ImageData` を極座標で回して渦にする。R/G/B を少し違う角度から
  拾うことで色ズレが出る。半分の解像度で計算してから引き伸ばしている。
- **設定** … 配色（Auto/Light/Dark）と動きのオンオフ。`localStorage` に保存。

## まだ入っていないもの

- 画像の破れた縁（方向性A/B/Cが未決のため保留）
- Contact フォーム、プライバシーポリシー
- Works の2カテゴリ分け（いまは8件を一列で送っている）
- アクセス解析
